You choose where Along looks.

This development extension provides one feature: discover products as you browse supported public sites, then discuss them in your existing Along conversation.

What is read and sent

After you opt in, enabled pages can provide their URL, product title and structured product details, or selected public post captions. These are sent to the Along server address you configure for matching. The server may use its configured AI and product-search providers. The server operator is responsible for identifying those providers and their retention terms before production deployment.

The extension does not read input fields, private messages, passwords, cookies, account pages or checkout pages. It does not place orders, alter shopping links, insert affiliate codes or track browsing history.

Optional visual discovery

Chrome requires the broad all-sites permission for automatic screenshots. If you separately enable it, Along limits use to the active, focused browser tab on an enabled supported site. It crops the visible video or main post-photo region locally, limits the JPEG to 640 pixels on its longest edge, and sends that crop to the Along server only when the server reports vision availability. The original screenshot is not stored or uploaded. Audio is never captured. Browser access is broader than Along's internal site allowlist.

Storage and controls

Preferences and your enabled-site list are stored locally. The pairing bearer token and recent discoveries use extension session storage restricted to trusted extension contexts. Tokens are never exposed to websites or content scripts. Closing the browser clears this session storage. Disconnect removes the token and recent discoveries; Clear discoveries removes the results. Pause stops observations. Disable a site to stop detection there; browser settings also let you revoke access.

Demo and live results

Demo mode is off by default and must be enabled explicitly. Demo results use authored fixture data and carry a visible label. They are not live Coupang availability, price or identity claims. Search suggestions and similar matches are distinguished from verified exact listings.

Limited use

Along uses browsing data only to provide the discovery feature the user enables. It does not sell browsing data or use it for advertising. Use of data received through Chrome APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Before publishing

This is a development build. A production release requires a public privacy policy with an identified operator, contact details, actual service providers, server retention/deletion rules, and accurate Chrome Web Store disclosures. This page documents extension behavior; it does not assert store approval.
