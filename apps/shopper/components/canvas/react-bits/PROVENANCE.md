This is the Circular Carousel CSS 3D ring component, not Circular Gallery.
Along adaptations: controlled activeIndex, no stock-photo defaults, contain-fit product images,
no local keyboard focus changes in controlled mode, and stop animation scheduling when settled.
The wrapper disables autoplay, free drag, parallax and stretch: gestures request authoritative
shopping focus, then the accepted product index rotates the ring. Reduced motion and missing
CSS 3D support use a static product image with the same accessible controls.
