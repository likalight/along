## Data conventions

- **Prices:** USD reference item / selected-kit prices. Shipping, tax, import costs and additional hardware are excluded unless explicitly included. US-oriented sources are used; the Anker UK product reference has an explicitly synthetic USD placeholder, not a currency conversion.
- **Provenance:** `observed_page` is an extracted product-page amount; `search_snapshot` is indexed evidence. `search_range_floor` / `from_price` / `from_price_search_snapshot` are minimum or starting amounts. `manufacturer_rrp` is recommended retail; `historical_page` is a legacy amount; `demo_estimate` is synthetic. None is a checkout guarantee.
- **Availability:** Seller / snapshot-specific. `unknown` is not a stock claim. `in_stock_search` is indexed evidence. Backordered, special-order, available-soon, out-of-stock, unavailable and discontinued states are retained explicitly. Conditional shipping language and generic notification widgets do not establish inventory.
- **Reviews:** Real observed aggregates / counts where captured; `null` means missing, never zero. Some newly retrieved ratings are indexed or publisher-rounded; the product file identifies this weaker precision. A star-only rating can exist without a written review: MIC-099 has one rating and zero written reviews, distinguished in its file and JSON. Exact-kit reviews are kept separate from related-model or family ratings. Review summaries describe captured feedback and do not establish speech-to-text performance.
- **Suitability:** Café / office fit scores are synthetic 1–5 hypotheses for demo filtering, not customer ratings or measured recognition accuracy. Hardware cost and stock are not part of those scores. Detailed guidance lives in each product file.
- **Audio paths:** Listening ANC differs from outgoing microphone noise reduction. Close placement, polar pattern, processing and the host recording path all matter. An omnidirectional lav or meeting puck is included for comparison; it is not presented as a directional noise-rejection device.

## Product index

Use the stable `id` to join data. “Stars / count” is customer-review data, not the demo fit score. Price provenance and review precision must travel with the numeric values when importing. All 100 products have individual reference files.
