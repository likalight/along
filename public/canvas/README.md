# Canvas media

All SVGs are original schematic illustrations authored for this demo. They are proxy assets, not manufacturer photography or a promise of a product's exact appearance. Brand/model/variant text remains authoritative for identity. Replace them with licensed catalog images at integration.

`placement.webm` is an original six-second silent diagram recorded with browser Canvas/MediaRecorder. Attribution: Along demo team, 24 October 2026. It illustrates close microphone placement and warns that nearby voices still matter. It is not an external review, product recording or measured dictation test. `placement.vtt` supplies English captions. No third-party audio or video was copied.

Missing bag media is intentionally represented by a null URL in the fixture; no external fallback is invented. Browser checks separately exercise an unavailable video response.
